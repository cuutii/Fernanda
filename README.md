# 🤝 Fernanda — Landing de Consultoría en RRHH

Landing page profesional para empresas de **consultoría en Recursos Humanos**. Presenta los servicios de gestión de talento, una sección "sobre nosotros" y un formulario de contacto. Funciona como plantilla lista para personalizar con los datos de cualquier negocio.

## Características

- Estructura de una sola página con navegación por secciones: **Inicio**, **Servicios**, **Sobre nosotros** y **Contacto**.
- Servicios destacados: reclutamiento y selección, capacitación y desarrollo, consultoría en RRHH y gestión de nómina.
- Formulario de contacto (nombre, email y mensaje).
- Diseño limpio y profesional, con estilos en un archivo aparte (`style.css`).
- Sin dependencias: se abre directamente en el navegador.

## Demo

## Tecnologías

- HTML5
- CSS3

## Cómo usarlo

1. Descargá el repositorio.
2. Abrí `index.html` en tu navegador.
3. Para usarla como plantilla, editá los textos de `index.html` y los colores de `style.css`. El formulario se puede conectar a un servicio de envío de mails cuando se necesite.
